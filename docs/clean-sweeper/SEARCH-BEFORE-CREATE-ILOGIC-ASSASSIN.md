# CLEAN SWEEPER — Search Before Create / iLogic Assassin implementation directive

Platform authority: https://github.com/Waynitos/BEEXCITED-AI/blob/main/governance/SEARCH-BEFORE-CREATE.md
Status: DOCUMENTED, not automatically enforced. MU-approved principle, 2026-11-16.

Before creating or rewriting iLogic, research existing successful internal rules, function archives, historical MAD experiments, Inventor/Vault vendor examples and compatible public patterns. Record source paths/links, exact function versions, Inventor version, evidence, and compare REUSE / ADAPT / COMPOSE / CREATE. Check entire entry-point-to-save workflow, not just isolated helper functions.

Mandatory iLogic Assassin audit questions: Where are drawings actually stored? How are oDwgList and sDwgEntryPath passed? Is GA traversal AllReferencedDocuments or recursive filesystem? Are documents already open? Which property sets and Parts List overrides are modified? What does the complete dialog count? Are title-block revisions/dates protected? Are all candidate updates saved and read back?

Origin: BLACKBOX-15, https://github.com/Waynitos/MAD-SSSOT/issues/15. Preserve working baselines and rejected functions as compounding intelligence; never upgrade source review to workplace validation without logs.

Minimum evidence artifact for each substantive new rule: PRESEARCH record, candidate comparison, selected pattern, source provenance, known defects, test population, regression checklist and acceptance evidence.
