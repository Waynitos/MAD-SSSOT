# SIAPlus Guiding Framework

## Core Roles

| Role | Function | Description |
|------|----------|-------------|
| **SSSOT** | Memory | Remember what we've learned. The living single source of truth. |
| **MAD** | Validation | Challenge what we think we know. The adversarial critique loop (AA, DA, SSA). |
| **SIAPlus** | Evolution | Find what could be better. Continuous improvement of methods and protocols. |
| **TWEPAN** | Momentum | Celebrate and communicate what we've discovered. |

## Guiding Principle
**Assume Today's Best AI Solution Is Temporary.**

## TWEPAN Byline
**We Don't Just Celebrate Wins. We Celebrate Win-Wins.**

This framework sits above the operational MAD agents and the GitHub SSSOT repository.
