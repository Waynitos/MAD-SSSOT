# Topic Type: General MAD

**Use for:** Any topic that doesn't fit a more specific category. Freeform — standard AA→DA→SSA cycle with no pre-configuration.

## When to use this
Use General MAD only when no other topic type fits. If in doubt, check the other topic types first — a more specific type will give better DA pressure angles and a more useful SSA output.

Good candidates:
- Decision-making (career, purchase, strategy) that isn't product comparison
- Planning or scoping a project
- Evaluating a proposal or argument
- Any one-off question where completeness matters

## AA Framing
Build the strongest, most complete case for the topic as given. No domain-specific framing — follow the standard AA system prompt.

## DA Pressure Angles
- Apply the standard DA system prompt
- Source Quality Audit (mandatory on every run)
- Ask: what topic type does this most resemble? Apply those DA angles too.

## SSA Requirements
- Standard SSA output
- Always close with next-best alternatives and horizon analysis, even for non-product topics (e.g. alternative approaches, alternative framings of the question)

## Checklist
→ None pre-assigned. SSA should note which checklist would apply if one existed.
