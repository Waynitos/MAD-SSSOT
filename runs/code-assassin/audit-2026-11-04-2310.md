### FINDINGS

**1. [CRASH RISK] Sub Main ~Line 133 — `GetDirectoryName` null dereference in project-root detection**

`System.IO.Path.GetDirectoryName("C:\\")` returns `Nothing` in .NET. If the walk reaches a drive root, `sCandDir` becomes `Nothing`. The next loop iteration passes `Nothing` to `GetFileName()` (also returns `Nothing`), so `sDirName.ToUpper()` throws `NullReferenceException`. This crashes the script before any files are processed.

```vb
' Current (buggy):
If sParent = sCandDir Then Exit Do

' Fix:
If sParent Is Nothing OrElse sParent = sCandDir Then Exit Do
```

**2. [CRASH RISK] Sub WalkTree ~Line 490 — Opened documents accumulate and are never closed**

`WalkTree` calls `ThisApplication.Documents.Open()` to open child documents but has no `bOpenedHere` tracking — every document it opens stays open for the entire run. For assemblies with 100+ parts, Inventor's internal document-pool limit can be hit mid-walk, causing later `Open()` calls to fail silently and parts to be dropped from the rename map.

```vb
' Fix: track whether WalkTree opened the doc, then close after recursion
Dim bOpenedHereWalk As Boolean = False
If oChild Is Nothing Then
    Try
        oChild = ThisApplication.Documents.Open(sRefPath, False)
        bOpenedHereWalk = True
    Catch exOpen As Exception
        ' ... existing log ...
        Continue For
    End Try
End If

' CC check here, then recurse:
WalkTree(oChild, ...)

If bOpenedHereWalk Then
    Try : oChild.Close(True) : Catch : End Try
End If
```

**3. [ILOGIC] Function ComputeNewName ~Line 383 — No "under old project root" boundary guard**

The function only excludes `CONTENT CENTER` paths and files already in the target folder. Any `.iam`/`.ipt` referenced by the GA that lives *outside* `sOldProjectRoot` (shared corporate library parts, JC parts from a different project folder) will be queued for copying and re-prefixed. The header comment states *"ALL files under the old project root folder are copied"* but the code doesn't enforce that boundary.

```vb
' Add at the top of ComputeNewName (requires sOldProjectRoot passed as parameter):
If sOldFull = "" Then Return ""
If Not sOldFull.ToUpper().StartsWith(sOldProjectRoot.ToUpper()) Then Return ""
```

Note: `sOldProjectRoot` is currently not passed to `ComputeNewName`; would need signature update.

`oDoc2.PropertySets("Inventor User Defined Properties")` is called three times in succession (once each for `CS_RootSource`, `CS_RootGUID`, `CS_RunCount`). Each call traverses the PropertySets collection. Cache the reference once:
