### FINDINGS

**1. [ILOGIC] Line ~806–814 (v2.2.11): Silent design-view activation failure — no log entry on miss**

```vb
If sSrcDV <> "" AndAlso sExtU2 = ".IAM" Then
    Try
        Dim oNewAsm As AssemblyDocument = TryCast(oNewDoc2, AssemblyDocument)
        If oNewAsm IsNot Nothing Then
            oNewAsm.ComponentDefinition.RepresentationsManager _
                .DesignViewRepresentations.Item(sSrcDV).Activate()
            Try : System.IO.File.AppendAllText(sLogPath, "DV-ACTIVATE: " & ...) : Catch : End Try
        End If
    Catch : End Try    ' ← bare Catch swallows the exception silently
End If
```

`DesignViewRepresentations.Item(sSrcDV)` looks up the view by name in the new assembly's COM collection. If the view doesn't exist (possible when SaveAs creates a copy that initialises with a different default view name), the COM call throws `System.Runtime.InteropServices.COMException`. The bare `Catch : End Try` swallows it silently — no "DV-FAIL" entry is written to the log, so the operator cannot tell from the log whether design-view restoration succeeded or was skipped.

This is NOT a crash risk (the script continues normally), but it creates a **debuggability blind spot**: a user seeing no "DV-ACTIVATE" in the log won't know whether the view was silently restored to default or whether the name lookup threw.

**Suggested fix** — split the catch to log the failure:
```vb
    Catch exDV As Exception
        Try : System.IO.File.AppendAllText(sLogPath, _
            "DV-FAIL: " & sNewName2 & " (" & sSrcDV & ") — " & exDV.Message & vbCrLf) : Catch : End Try
    End Try
```
