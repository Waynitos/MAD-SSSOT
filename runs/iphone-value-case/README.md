## SSA Verdict

**Scenario A (Mac within 3 months):**
→ iPhone 16 Plus (new, AUD $1,299) + Mac mini M4 Pro (24GB, AUD $2,200) = AUD $3,249 net. Mac is the leverage point; phone savings go there.

**Scenario B (Mac deferred 6+ months):**
→ iPhone 16 Pro (Apple Certified Refurb, ~AUD $1,400–1,500). Same A18 Pro chip/camera as Pro Max, 1-year Apple warranty, only ~AUD $100–200 more net than 16 Plus. Better 5-year AI longevity.

**Critical finding:** Never use Amazon Renewed — Apple Certified Refurb (apple.com/au/shop/refurbished) only. AA's warranty argument collapsed when DA made this distinction.

**AA omission:** iPhone 16 Pro (non-Max) was the obvious middle option — same chip, same camera, smaller and cheaper. AA never mentioned it.
